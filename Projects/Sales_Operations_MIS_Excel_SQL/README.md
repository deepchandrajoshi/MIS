# Sales & Operations MIS Analytics — Excel & SQL

## Objective
Build a realistic management information system for a retail/e-commerce business using Excel, Power Query and SQL.

## Business Questions
- What is total revenue and profit?
- Which regions and categories perform best?
- Which products have high revenue but low margins?
- Which customers are most valuable?
- Which salespeople are above/below target?
- What is the monthly growth trend?

## Tools
- Microsoft Excel
- Power Query
- SQL Server / MySQL / PostgreSQL
- PivotTables & PivotCharts

## Dataset
- 50,000 sales transactions
- 5,000 customers
- 36 products
- 80 salespersons
- 960 monthly target records

## Recommended Workflow
Raw CSV → Power Query → Data Cleaning → Data Model → Excel MIS Dashboard → SQL Analysis → Business Insights

## Resume Value
Demonstrates advanced Excel, Power Query, SQL joins, CTEs, window functions, KPI reporting, data validation, business analysis and management reporting.

## Interview Talking Points
1. Why did you use Power Query?
2. How did you validate the raw data?
3. How did you calculate profit margin?
4. Why use a master-data structure?
5. How did you identify low-margin/high-revenue products?
6. How did you calculate MoM growth?
7. How would you automate monthly reporting?
8. What would you do if the source file format changes?
